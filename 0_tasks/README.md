# 0_tasks — what is being done

Roadmap, backlog, and per-task plans for front-data.

Convention across every repo under cloud:

- `0_ROADMAP.md`   direction
- `1_BACKLOG.md`   queued work
- `TASK-*.md`      one file per task
- `PLAN-*.md`      one file per multi-step plan

Sibling headers: `0_specs/` (what this repo is) and `1_configs/` (how the
repo runs).
